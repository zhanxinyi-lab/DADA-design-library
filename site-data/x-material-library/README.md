## 部署边界

本 PR 是目录数据增量，不是完整静态站点包：`assets/` 只收录本次 44 条新增记录的媒体，既有 187 条素材的媒体仍在当前 XD Sites 静态站点中。本目录不能单独作为部署根目录直接发布；同步时应将清单与新增资产叠加到完整站点资产树，保留原有资源和 UI。此 PR 不包含部署操作。
