## 复刻说明

对照站点已发布预览 `assets/2119151022014894260/preview.mp4`（与原帖同一条 958×720、14.4 秒视频）逐帧看过：

- 静止时是深色背景上的一枚圆角方块，中间有更亮的圆斑，光标落在方块边缘。
- 按下后先被压扁（更宽、更矮），随即鼓起、变亮，暖白色铺满画面。
- 按住期间亮度会来回鼓动；松开或连点结束后缩回原来的深色小方块。14 秒里这种胀起/缩回出现多次，时长不固定。
- 原画面里方块略偏左下。这里改到水平居中、略低于垂直中心，避免窄屏被裁掉。不画假光标。

自包含 WebGL。鼠标按下方块、触控，或 Tab 聚焦后用 Enter / 空格，都会触发同一套弹簧。`prefers-reduced-motion` 时不做弹簧，只在按住时直接切到发亮的鼓起状态。无外链。
