## 复刻说明

自包含单文件，无外链，也不引用外部字体或图片。

对照 `poster0.jpg`，以及 `preview.mp4`（实测 8.0 秒、720×540、30fps）。同目录 `preview.webm` 是 6.0 秒。登记里的 90 秒与文件不符，目录已改为 8 秒。包内没有 `preview.gif` 和 `video.mp4`，这两条悬空路径已去掉。

海报和成片都是近黑的夜景：一条玻璃搜索栏，栏里有细雨点，下面五个胶囊是 Clear、Light rain（成片里一直亮着）、Storm、Snow、Fog。8 秒里有人往栏里打字，天气选择没有切走。原句占位和「agent」没有搬过来。

这里保留的是搜索栏本身的反馈：栏内粒子、左侧图标和页面色调会跟着关键词变；没有天气词时改跟本地时段。五个胶囊写入对应关键词。聚焦时栏上有轮廓，清空后回到时段，对不上的词会单独写出「没有匹配的地点」。Tab、输入和 Esc 都能完成这些操作。系统开了减少动态时，色调、图标和粒子都直接停在新状态，不再做过渡。
