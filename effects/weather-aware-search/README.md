## 复刻说明

自包含单文件，无外链，也不引用外部字体或图片。

`poster0.jpg` 是原帖海报，`video`（`preview.mp4`）是原帖参考片，实测 8.0 秒、720×540、30fps。两份都是原站界面：英文占位 “Search anything with agent”，以及 Clear / Light rain / Storm / Snow / Fog。它们只作对照，不是复刻截图，也不是复刻成片。登记里的 90 秒与参考片不符。包内没有 `preview.gif` 和 `video.mp4`，这两条悬空路径已去掉。

`preview.webm` 是打开 `code/index.html` 后自己录的屏，8.0 秒、1280×720。从「晴」开始，大约每 1.6 秒切到小雨、暴风、雪、雾，能看到色调、图标和粒子一起过渡。画面里没有原站那句英文。

这里保留的是搜索栏本身的反馈：栏内粒子、左侧图标和页面色调会跟着关键词变；没有天气词时改跟本地时段。五个胶囊写入对应关键词。聚焦时栏上有轮廓，清空后回到时段，对不上的词会单独写出「没有匹配的地点」。Tab、输入和 Esc 都能完成这些操作。系统开了减少动态时，色调、图标和粒子都直接停在新状态，不再做过渡。
