## 复刻说明

自包含单文件，无外链。对照公开落地页里能直接核对的三件事，而不是把原品牌整页搬过来：

- 放大镜可以按住拖走，镜片把底下的版面放大。
- 「X 光」画出实测像素：宽、高、缝，线的两端有刻度，数字来自当前布局。
- 有些批注平时看不见，只有镜片盖住才出现。右上角计数从 0/6 走到 6/6。

原帖赞的是 Bricolage Grotesque、Space Grotesk、IBM Plex Mono。这三套是免费商用字体，但本页不能引外链，目录里也不另附字体文件，所以标题、正文、标尺分别用衬线、系统无衬线和等宽系统字体代替。

没有使用 metic 的名称、标志、句子、坐标、照片或放大镜海报。文案和版面是另一套工作台，方便换品牌后再用同一套交互。

站点导出里只有约 8 秒的 poster / preview。条目写的 71 秒全片（`video.mp4`）不在这份导出里，全片镜头没有逐帧复刻。放大镜、X 光和隐藏批注这些机制，以公开页面结构和短预览为准。

系统开启减少动态效果时，放大镜不自己晃动，仍可用拖拽或方向键移动。
