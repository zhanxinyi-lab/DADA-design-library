## 复刻说明

对照站点里的 `preview.mp4`。文件是 8 秒、720×678、30 帧（登记写约 23 秒，以看过的片子为准）。黑底，等宽字符。大部分是顺着弧线排开的短划和竖线，铺成一张星图网；另外有几团更密的字符，夹少量黄、青和暖色，在网上缓缓移动。空处偶尔有单独的 `+` 或 `x`。不是整屏往下掉的乱码。

字符和轨迹是按这个疏密自己排的，没有搬原视频，也没有逐帧描原片。只用系统等宽字体，无外链。系统开启减少动态效果时停在一帧，窄屏会按视口重算字号和列数。
