## 复刻说明

原帖说明碎块、金缝和金屑都是程序生成，没有使用模型。站点 8 秒预览是黑底棚拍：暖灰陶瓷器、细金缝、缓慢换角度，不是带标题的平面海报。

这条是自包含 WebGL，不加载 three.js，也不使用原画面、原品牌字或对方几何。碗体由经线旋转生成，裂纹是体积 Voronoi 切出的碎块，金色填缝留在缝隙中央，并带少量金屑。拖动画布可转角度；「裂开 / 合拢」把缝拉开再合上。配色、碎块数和缝宽可改。`prefers-reduced-motion` 时停在静帧，只在操作时重画。
