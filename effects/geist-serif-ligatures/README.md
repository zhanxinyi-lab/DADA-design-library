## 说明

此单页同时展示两种明确标注的 Geist 字体能力：

- `GeistSerif.woff2` 的真实 `ELSH` 轴用于点号、标点等受影响字形的实时样例；页面同时以真实 `ss01` OpenType 特性并排展示 `aR` 默认 / 替代字形。
- 连字对照使用同一字体家族的 `GeistSans.woff2`。它的 OpenType `liga` 表含有 `f+i`、`f+l` 和 `f+f` 替代规则；页面将开关打开与关闭的相同文本并排展示。

随附 Geist Serif 文件的 GSUB 表没有标准 `liga` 特性；因此页面不声称 fi/fl 连字属于 Serif 字体，而是把实际连字清楚标为 Geist Sans。随包收录基于 Vercel 官方 `geist-font` 仓库字体文件生成的本地 WOFF2、Geist Sans WOFF2 与 SIL Open Font License 1.1；来源：https://github.com/vercel/geist-font。该页展示静态字形与字体特性，不推断或声称复刻原帖动画。
