## 复刻说明

自包含单文件，无外链。对照原帖、海报和约 8 秒站点预览里能稳定看出的结构：剖开的住宅、分色管线、步骤卡，以及点选对应关闭件。

原帖写明用 Blender 和 Three.js 做了八个动手情境。预览和两张静帧看不清那八条各自的步骤，仓库里也没有可引用的源码。这里不搬原模型、原画面或原文案，只把水、电、燃气三路做成可配置手册：点管线认路，或直接点总阀 / 总闸把它关掉。改脚本顶部 `const THEME` 可换名称、房间名、颜色和步骤文案。

页面标明这是设计演示，不是真实应急指引。系统开启减少动态效果时，管线不再流动，关闭反馈立即呈现。
