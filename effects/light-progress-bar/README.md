## 复刻说明

自包含单页，无外链、无原视频、无截图。深色背景上是一条胶囊灯带：红粉灯珠从左逐格点亮，百分比贴着前沿走，到尽头整条铺满，再退回去。数值来自 15.13 秒、958×720 预览里灯带右沿的明暗变化，不是线性猜的单次加载。

原帖正文只有 “Light progress bar.”，没有代码、演示链接或许可证。作者站点上的 Liquid Tags 是另一条玻璃进度，未当作本件来源。本页是独立绘制，不复制画面素材。

预览里没有稳定的鼠标光标，看不出拖动手势；成片本身在自己改变进度。页面因此自动播放同一条灯带。滑条、点击灯带和方向键只用来停在 0–100 的某一格上核对，不声称原帖有这些控件。窄屏仍是单行灯珠。系统开启减少动态效果时停在 64%，不自动播；焦点停留在灯带上时，方向键、Home、End 仍可改数值。
