## 复刻说明

自包含单文件，无外链。对照原帖 118 秒视频（1080×526）里能稳定读到的交互，以及站点 `poster0.jpg` / `preview.mp4`。站点 `video.mp4` 为 404；站点预览只有 8 秒、720×350，且只覆盖画布局部，不包含分屏。

浅色画布上散落若干产品。拖拽或滚轮可以平移画布；点一件后变成左右分屏：左边是放大的产品，右边是名称、价格、色点、尺寸和放入。色点会改这件产品的颜色，关闭后回到原来的画布位置。

原片商品是实拍，商标是 forme®。这里不使用那些照片，也不使用该字标。产品是原创矢量几何体，名称和价格也是演示用的。
