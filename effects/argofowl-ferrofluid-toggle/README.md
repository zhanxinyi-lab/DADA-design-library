## 复刻说明

自包含单文件。点按或用键盘切换浅色 / 深色。浅色是暖灰场景里偏左的黑色液团，偶尔泛起铜色高光；深色时液团变宽、呈铜色，画面从下方和边缘压暗。无外链，无图标和文字控件。

## 来源与许可边界

公开帖作者为 argofowl，正文写 “ferrofluid toggle made with opus 5.5”，并称没有 three.js 或其他外部库、单个 HTML、声音在浏览器里生成。未找到源代码仓库，也没有明确的再使用许可。

本目录只有原创实现。不包含原视频、截帧、音频或作者素材，也没有照搬任何未公开源码。画面依据是原片约 32 秒的取证：浅色保持暖灰（中心约 #e3ddd6），液团偏左且偏黑；深色时下半和边缘接近黑，液团变成更宽的铜色横带并保持稳定；两种状态之间大约 0.3–0.5 秒。浅色静止段里，铜色高光会一阵阵出现再消退。

原视频文件带有 AAC 音轨。这里没有逐段听清音效和画面的对应关系，所以不加声音，也不放静音开关。
