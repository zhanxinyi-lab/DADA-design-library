## 复刻说明

自包含单页，黑底。静止时只有一枚蓝色胶囊按钮，没有金币。按住按钮后，金币先在按钮上露出正面；松手或按住一会儿后，金币离开按钮，快速升到画面顶部。到顶后翻转已经转正，币面放大并停大约半秒，再落回按钮里收起。蓝色按钮全程留在原处。上升和落下都很快，只有顶部用缓动把币面留给人看。这对应原帖的 “no slow motion, jus' easing for the detail hang time”，不是整段慢放。

币面是新绘的环纹，不是公开笔里的图形。页面不使用那一笔的文案、字体、音效或脚本。
