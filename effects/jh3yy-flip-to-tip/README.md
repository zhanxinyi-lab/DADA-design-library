## 复刻说明

自包含单页。按住硬币就抛起：上升和落下都很快，靠近最高点时垂直运动和翻转都放缓，币面正对镜头多停一会儿。这是原帖写的 “no slow motion, jus' easing for the detail hang time”，不是把整段放成慢动作。松手后这一抛会走完；若还按着，落地后再抛，并换另一面着地。

22.3 秒原片是深色屏幕录像，亮部是一枚硬币在画面中移动。公开笔 [flip to tip 🪙](https://codepen.io/jh3y/pen/NPqxRxa) 的可见文案是 “hold to flip coin”。页面因此用按住触发，不另造拖拽或滑块。
