## 复刻说明

自包含单文件，不引用外网字体、脚本或原站资源。滚动时，银色粒子先组成一条游动的锦鲤，再散开收成清酒瓶，最后在瓶旁收成一只杯。改脚本顶部的 `BRAND` 可换名称、颜色和文案。

运动对照的是原帖 54.65 秒视频，以及素材站已发布的 8 秒 `preview.mp4`（只有开场锦鲤）。`koiyama.aura.build` 本次只画出 “Made in Aura”，没有画布，不能当作可交互的原页面核对，也没有把它的脚本搬进来。
