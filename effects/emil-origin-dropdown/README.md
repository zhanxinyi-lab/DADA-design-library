## 复刻说明

自包含单文件，无外链。白底上并排放两枚 Options。菜单左缘和按钮左缘对齐，完全展开后两边长得一样，差别只在缩放原点。

左边 `transform-origin: center`。菜单缩向自己的中心，顶边离开按钮，中间空出一截。右边 `transform-origin: top left`，原点在按钮左下角那一侧，菜单贴着按钮长出来，收回时也收进同一个角。

预览里一次开合约几帧。这里用同一时长、同一缓动，把开合放慢，方便看见那截空隙。点任意一枚 Options 会停下自动播放，并让两边一起开或合。系统开启减少动态效果时，两边直接展开，不再缩放。

菜单里的名字、邮箱和条目是预览画面里能读到的占位内容，不能跳转。
