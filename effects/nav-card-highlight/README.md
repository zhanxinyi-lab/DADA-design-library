## 复刻说明

自包含单文件，无外链。行为参考是同一块高亮跟着当前卡片移动并改变宽高。参考帖没有可核验的公开演示，许可也未核验，因此没有复制其代码、锚点定位片段或画面。卡片文案和布局是原创的。

默认四张卡宽高不同。细指针悬停时，高亮滑到该卡并改成它的宽高，铺上浅色底，并浮出一条链接文字。键盘焦点只预览同一块高亮；Enter 或 Space 才切换当前项。触控只在点选后改变当前项。系统开启减少动态效果时，高亮立即到位，不做滑动。高亮没有描边，滑动时不会扫过中间文字。
