## 复刻说明

自包含单文件，无外链。对照预览 `preview.mp4`：OpenCV 实测 720×406、30fps、240 帧、8.0 秒。

8 秒里要复刻的是这一小段，不是后面的整页：

- 超大镂空字母先贴在视口下沿。
- 往下滚，字母连续升到顶上，中间没有跳变。
- 色块、简单图形和短说明从字母空隙里穿过去，字母盖住实心部分。

字母是自绘占位字 PORTAL，描边和字腔都是新的。不使用原站那组单词、说明、照片、字体和时钟插画。

滚轮、触摸和键盘改的是同一段 0 到 1 的进度，停下就停在当前这一帧。系统开启减少动态效果时直接画顶上的目标形态，不排动画帧；滚轮、触摸和键盘这时不再改进度。这个偏好打开或关掉时都同步画一次，关掉后按关掉前的进度画，不另开动画帧。窄到 320 宽时字母仍留在画面里。
