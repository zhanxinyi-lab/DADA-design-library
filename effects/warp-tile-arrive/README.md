## 复刻说明

自包含单文件，无外链。对照预览 `preview.mp4`：OpenCV 实测 720×450、30fps、240 帧、8.0 秒。

8 秒里要复刻的只有这一小段：青绿色底上，一道扭曲从中心拉开。滚动时，纯色块从中心被拉长、弯着飞开，最后落成松散的方块。大标题只是衬底。

不使用原站标题、导航、人名、肖像和预览图里的页面文案。标题写成中性占位 SAMPLE BOARD，卡片是纯色块。

滚轮、触摸和键盘改的是同一段 0 到 1 的进度。位置、拉长和弯曲都跟着这段进度连续变化，没有滚过某个阈值就整组切换的帧。停下就停在当前这一帧。系统开启减少动态效果时直接画落定的方块，不排动画帧；滚轮、触摸和键盘这时不再改进度。这个偏好打开或关掉时都同步画一次，关掉后按关掉前的进度画，不另开动画帧。窄到 320 宽时色块和标题仍留在画面里。
