## 复刻说明

自包含单文件，无外链。clean-room：只对照约 8 秒预览里看得到的隧道格子自己画。没有搬原视频、字体、图片，也没有搬品牌名、评价文案或标识。

画面是深色背景上的透视方格隧道：地板、天花板和左右墙的格子汇向同一个灭点，格子之间留缝，远处置空。静止时只有淡线框。

鼠标移动，或手指按住滑动，当前位置的格子变成橙色像素方块。周围格子随后被点亮，近处更亮、远处更淡，不是整屏一起闪。指针离开后，亮度再慢慢衰减熄灭。

窄屏会减少列数和纵深，格子仍然铺满画面。系统开启减少动态效果时，不跟指针，也不播放扩散，只停在一帧静态网格。
