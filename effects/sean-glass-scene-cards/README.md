## 复刻说明

自包含单文件，无外链。clean-room：只对照 2026-11-19 素材包里的预览和海报自己写。预览是 8 秒、720×406、30fps。没有嵌入原片、截帧或房间照片。

四张玻璃胶囊叠在虚化客厅上，点中的那张换成白底标题和彩虹描边，右侧亮起一颗小点。房间光线和色温跟着过渡。指针停在别的卡片上不会提前切换。

文案和亮度按画面里能读到的：

| 场景 | 说明 | 亮度 |
|---|---|---|
| Morning | Blinds open · 5000 K | 80% light |
| Movie | Projector · blinds down | 12% light |
| Dinner | Pendant lights · 2700 K | 46% light |
| Night | Path lights only | 4% light |

这 8 秒里先后停在 Morning、Movie、Dinner。Night 只作为未选中的卡片出现，夜间低照度路径灯是按这张卡片的文案画的，不是从选中帧描下来的。

上下方向键也能换场景。系统开启减少动态效果时立刻换场，彩虹描边不再转动。系统开启降低透明度时，玻璃改成实底。客厅是页面里的色块，不是原照片。
