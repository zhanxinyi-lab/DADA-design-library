## 复刻说明

自包含单文件，无外链、无参考包媒体。行为参考是横滑时只突出一张卡片，当前卡变宽并出现标题，两侧收窄。参考目录和参考包的许可都未核验，因此没有复制其代码、截图、标题或图片。

可以用指针拖动、触控滑动、点击卡片，或使用上一张/下一张。拖动时轨道跟手，松手后落到最近的一张。当前卡保持在轨道中间，两侧收窄并互相叠放。变宽时露出同一张原创色块的更多部分，色块尺寸不变。方向键在这组控件内切换，焦点在卡片上时会跟着移动。系统开启减少动态效果时，位置、裁切和标题立即切换。
