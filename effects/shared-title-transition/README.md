## 复刻说明

自包含单文件，无外链。

`preview.mp4` 和 `poster0.jpg` 是原帖素材，不是这条复刻的成片。mp4 为 720×960、30fps、240 帧、8.0 秒，画面是手机外框里的 Essays 列表，底下有 Navigation / Card / Player 说明，以及 @kubai087 / Lumnno。海报同样是这张原帖静帧。它们只用来对照动作，不能当作本页预览。

目录里的 `preview.webm` 是本页 `code/index.html` 的屏录：1200×750、vp9、30fps、240 帧、8.0 秒。画面从「目录」列表点进「文集」，行标题放大成页标题，「目录」缩成返回；滚动后标题收到顶栏正中，再退回列表。没有手机外框、原帖水印和底部说明。

原帖成片前大约 5 秒是 Navigation，大约 5.6 秒之后切到卡片展开。卡片、播放器、搜索、图表和菜单这里不做。

画面上标的数值直接用在这段过渡上：

- 行标题到页面标题：缩放 0.53 → 1
- 原标题到返回标签：缩放 1 → 0.47
- 滚动 64px：标题收到顶栏正中
- 整段 580ms，`cubic-bezier(.32, .72, 0, 1)`

点击、触控和键盘 Enter / Space 都改同一段进度。从左缘向右拖也可以把这段进度拖回来；松手后从当前进度播完，不在中点把界面换掉。滚动只改「收进顶栏」这一截，并和推进进度乘在一起，所以退回时标题会从顶栏里连续走出来。

系统开启减少动态效果时，推进和返回直接停在终态，不排动画帧。滚动仍然跟着手指走，因为它不是定时动画。

320 和 390 宽都在页面内换行和滚动，不出现横向滚动条。
