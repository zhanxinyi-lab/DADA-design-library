## 复刻说明

自包含单文件，无外链。对照的是站点预览 `preview.mp4`：720×960、30fps、240 帧，8.0 秒。目录里写的约 31 秒和这条文件对不上。

前大约 5 秒是 Navigation：目录列表里点一行，这一行的标题放大成下一页的大标题，原来的「目录」缩成左上角返回；页面向左让出，新列表从右侧进入。停住后往下滚动，大标题收进顶栏并居中。返回时沿同一段进度收回，停在半路再返回也不会把两页对切。大约 5.6 秒之后预览切到卡片展开，那是同一条帖里的另一段，这里不做。

画面上标的数值直接用在这段过渡上：

- 行标题到页面标题：缩放 0.53 → 1
- 原标题到返回标签：缩放 1 → 0.47
- 滚动 64px：标题收到顶栏正中
- 整段 580ms，`cubic-bezier(.32, .72, 0, 1)`

点击、触控和键盘 Enter / Space 都改同一段进度。从左缘向右拖也可以把这段进度拖回来；松手后从当前进度播完，不在中点把界面换掉。滚动只改「收进顶栏」这一截，并和推进进度乘在一起，所以退回时标题会从顶栏里连续走出来。

系统开启减少动态效果时，推进和返回直接停在终态，不排动画帧。滚动仍然跟着手指走，因为它不是定时动画。

320 和 390 宽都在页面内换行和滚动，不出现横向滚动条。
