## 核对过的运动

- 依次，约 14–21 秒：收起时文字从上到下熄灭，约 18.23 秒到 18.55 秒走完，间隔大约 40 毫秒。约 20.29 秒起的展开也是上先下后。侧栏宽度还在继续缓出，收起大约 1.3 秒，展开大约 1.1 秒，所以文字错开结束时宽度还没到位。
