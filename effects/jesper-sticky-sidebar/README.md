## 复刻说明

自包含单文件，无外链。clean-room：只对照原帖这句话 “Smooth sticky in the wild. Subtle, but makes the difference.”，以及素材包里的 `preview.mp4`（720×362、30fps、240 帧、8.0 秒）和三张静帧。没有使用原站脚本、字体或图片，也不嵌入成片。

名单、标记和句子都是新的。原片里的客户名、商标、导航和正文没有搬过来。

8 秒预览里能看清的运动：

- 开头约 0.6 秒，左侧名单停在画面中部，名字全是黑体，下面还没有标记。
- 大约 0.7 秒起右侧正文连续滚动，名单没有立刻钉死。它先被带着走，再从约 2.8 秒的偏下位置缓进画面上沿，约 3.6 秒停住；右侧这时还在动。
- 停住之后当前名字保持黑体，其余变灰，名单下面的色块标记交叉换掉。约 3 秒是第一项，约 4 秒换成第二项。
- 大约 3.9 秒到 5.6 秒画面往回走，名单跟着离开上沿，高亮也松开，名字回到全黑。
- 大约 6 秒到 7.9 秒再次往下滚，名单又缓缓吸回上沿，右侧正文仍在滚动。

页面用同样的关系：滚动目标先算「还没到 / 吸住 / 被这一段底部顶走」，画面位置再以约 0.42 秒的时间常数去追这个目标。所以快滚时名单会落后一拍，停住前是减速，而不是瞬间卡住；滚出这一段时也是缓缓松开。

可以滚动，也可以点名字跳到对应段落。没有操作、也没有减少动态效果时，会自己慢慢滚过吸住和一次换标。滚轮、触摸、按键或点击会接手。减少动态效果时直接停在目标位置，不自动滚动，颜色和标记立刻切换。
