## 复刻说明

对照预览自己画的单文件，没有搬原视频，也没有 illos.dev 的标识或商标。

近黑底上有淡网格。蓝色方点铺成一只杏仁眼，上面另有一条分开的眉弧。虹膜是几圈深浅不同的点，正中留出黑瞳孔，绿色方框标着 SCANNING。眼赤道附近有一些绿点。旁边是扫描界面的细线和短标签：BROW、IRIS、NIR 850、坐标，左下角是 TRACKING 点数。

眼睛偏在画面左侧，右边留着给光标走。指针在眼里时，瞳孔和虹膜明显跟着走，眼形仍张开。指针贴到眼角时，眼睛变扁，同时朝指针那一侧拉长。指针再往上、往外走到屏幕远处时，眼睑不再拉满，只留一点朝向，和贴着眼角时分开。细线汇到 TARGET。眼睛中心一小圈里瞳孔不动，出了这圈再平滑跟上。鼠标和触摸都能带动。没有指针时回到正视。

系统开启减少动态效果时，不再跟随，停在正视的一帧。窄屏把眼睛缩进画面并改回居中，标签不会跑出屏幕。
