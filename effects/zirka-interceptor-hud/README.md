## 复刻说明

自包含单文件，无外链。原帖没有代码、代码链接或许可证。Awwwards 条目和公开产品页正文里也没有许可证声明，这里不声称已获许可。

对照的是站点 `preview.mp4`：720×540、30fps、240 帧、8.0 秒。条目里的 `duration_s: 19` 和文件不符。画面是橙色背景里的一台笔记本；笔记本、键盘和底座是成片的外框，不是网页。页面只做屏幕里的 HUD，不嵌这段视频、海报或原片里的无人机照片。

### 看得到、并且做进页面的

- 近黑底，一架自画的几何拦截机剪影在后面缓慢偏转、放大。剪影不是原模型。
- 顶栏：星标、ZIRKA、Threat / Features / Effectiveness / System，右侧 EN 和 Contact。菜单词在预览里小到读不清，和公开页导航用词一致后才写上。Contact 在预览里没有点开，这里只是字，不是表单。
- 0–3 秒：左侧 Max speed，中间数字从 224 增到 340，右下角小字 km/h，右侧 001。大约 1.5 秒后一圈点状刻度合拢，3 秒时停在 340。
- 3.2–3.7 秒：刻度消退，数字交叉淡化，出现一条短的锈橙色竖线。
- 3.7–8 秒：左侧换成 Flight time，右侧换成 002，数字从 14 数到 24。预览最后一帧仍是 24，后面没有停稳，所以不把 24 当成最终航时。
- 播完后停一小会儿再重放。「再看一次」只重放这一段。

公开页上还有 Radius、Altitude、Target tracking。这 8 秒里没出现，不做。

系统开启减少动态效果时，直接停在 340 km/h、刻度合拢的那一帧。
