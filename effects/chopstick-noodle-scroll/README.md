## 复刻说明

自包含单文件，Canvas 2D，无外链。对照站点 `preview.mp4`：OpenCV 实测 720×406、30fps、210 帧、7.0 秒。

7 秒里要复刻的是这一段滚动，不是整站：

- 筷子夹起一团拌面。
- 往下滚，面条旋转拆开，虾、青柠、花生、豆芽等分开，并带标注。
- 再往下滚，食材自行落回盘里。标题随这三拍更换。

面条、食材和盘子都是自绘。不使用原片照片，不写原品牌名，不用原站字体和广告句。

进度直接跟滚动位置走，停住就停在当前这一帧，没有事后补间。方向键、翻页键、Home 和 End 也能推进或退回。系统开启减少动态效果时，直接停在落盘终态并当场画一次，不申请动画帧；这时滚动、滚轮、触摸和键盘都不再改进度，归位滚动条也不再补画第二帧。舞台是进度条，同步标出 0 到 1 的进度，aria-valuetext 写当前拍 lift / split / plate。窄到 320 宽时画面留在视口内。
