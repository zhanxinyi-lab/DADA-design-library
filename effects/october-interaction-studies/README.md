## 复刻说明

原帖是一组微交互，不是整站。这一页把四件事上下排开，不拆成四个目录，也不搬原品牌、原素材或成片画面。

- 拨盘选数：拖拨或点刻度都会改值，松手前就吸到最近的刻度，数字实时变。可以聚焦，用方向键加减。
- 对话框：从触发按钮的位置长开，舞台里的背景压暗。Esc 或点暗处关闭，焦点回到按钮；Tab 只在对话框里循环。
- 人数选择：一排选项，选中项有滑块。方向键只移动焦点，Enter 或点击才选中。
- 思考动画：节奏点在呼吸。点击或键盘可以提前收成结果，不等待也会自己收束。

系统开启「减少动态效果」时：拨盘直接跳到刻度，对话框瞬切，人数选项没有过渡，思考动画停住；开启期间点「开始想」直接给出结果，不排定时器、不排动画帧。

窄到 320 宽时，思考那一行会换行，文字宽度受卡片内容宽约束，不会顶到右侧内边距。
