## 复刻说明

自包含单页，无外链。clean-room：只对照素材包里的预览和静帧自己画，不嵌原片、截帧或房间照片，也不搬原品牌字标和家具模型。

清单把这条记成约 33 秒，但目录里的 `preview.mp4` 实际是 8.0 秒、720×406、30fps；`video.mp4` 不在素材目录里。8 秒里能看清的是：开头窗光和右侧台灯同时亮着；大约 3 秒夕照变暖；大约 4.5 秒窗外转暗，台灯还亮着；大约 6 秒窗光又亮起来，台灯仍然亮着。屏幕上的风景跟着变，但那是换画面，不是这次要复刻的部分。

这里把光源做成四盏可以同时开着的灯。点一盏，只改它自己的强度，其余几盏留在原来的亮度。墙、地面、桌面按各自面对的光源相加着色，混合色温是强度加权的开尔文。强度用大约 0.9 秒平滑过去，所以是连续过渡，不是两张图交叉溶解。

| 光源 | 色温 | 开着时照哪里 |
|---|---|---|
| 窗光 | 6500 K | 左侧窗、墙和桌面，偏冷 |
| 夕照 | 2400 K | 同一扇窗的暖色，能跟窗光叠在一起 |
| 台灯 | 2700 K | 右侧台面和墙 |
| 屏幕 | 5600 K | 显示器前方的一小块桌面 |

开头默认窗光、台灯、屏幕开着，夕照关着，对应预览第一帧「冷窗 + 暖灯同时存在」。四盏全关时房间留一点夜色，不是纯黑。

Tab 或方向键在四盏灯之间移动，当前焦点有双层描边。回车或空格开关。系统开启减少动态效果时，强度直接跳到目标，不补间，太阳位置和光线一起跳。
