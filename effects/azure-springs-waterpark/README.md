原帖写明：浮空岛上有三条滑水道、一个造浪池、一条漂流河和一群游客；可以造一波浪、跟随滑道上的人，以及切换一天里的时间。站点快照里的 `preview.webm` 长 6 秒、480×300、约 60 帧/秒：前段是日间乐园的持续运动，约 5.5 秒画面明显转暗。同目录没有 `video.mp4`。海报是同一座岛的静帧，标题是 Azure Springs。
