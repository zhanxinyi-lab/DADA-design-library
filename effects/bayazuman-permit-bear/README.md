## 复刻说明

自包含单文件，无外链。对照原帖约 8 秒预览：橄榄色底上先出现许可框，框下一只小熊抬着头看它；光标移到拒绝后，小熊不是换成背面静图，而是先仍面对对话框，再转身，然后往远处走小。

允许的一侧预览里没有播完。按条目说明做成另一段有先后的反应：先睁大眼，再跳起，落地后才举起爪子。小熊用画布自绘，不使用原模型。许可框用系统字体排字，按钮是「是 / 否」。

键盘可 Tab 到两个按钮，方向键在「是 / 否」之间移动，焦点有外圈。系统开启减少动态效果时，跳过补间，直接停在高兴或已经走开的姿态。
