## 复刻说明

自包含页面，照片和代码放在同一目录。对照原帖 6.9 秒视频：浅灰底上是 2×2 玻璃文件夹，不是线框图标。

画面里的字保持：

- My Files，3 items
- Archives，4 items
- Studio，3 items
- Collection，3 items

合上时，照片卡收在磨砂口袋里。左下角是名字和件数，右下角是加号或更多。Studio 是深色口袋，后面露出一张纸边。

悬停时，卡片从口袋上沿抽出来，叠成一沓。点一下摊成扇形，按钮变成关闭；再点合上。卡片从口袋后面滑出，不把下一排网格顶下去。

封面没有描原片插画，换成了示例照片。系统开启减少动态效果时不做过渡，点按仍能展开。
