## 复刻说明

自包含单文件，无外链。对照原帖 6.9 秒、1532×1080 视频，以及站点上的 `poster0.jpg` / `preview.mp4`。帖内和 inspora.design 作品页都没有代码。

浅灰画布上是 2×2 文件夹。画面里能稳定读出的字是：

- My Files，3 items
- Archives，4 items
- Studio，3 items
- Collection，3 items

约 0.45 秒起 My Files 展开并保持到约 1.8 秒，文件夹变高，下一排随之下移，约 2.3 秒回到网格。之后 Archives、Studio、Collection 各有一次更短的展开，约 6.2 秒回到四张都合上的网格。

封面里的具体插画在成片里对不齐，这里用原创的单色几何，不描原画。展开后只按读到的数量露出纸页，不编文件名。点一张会停住并展开它；系统开启减少动态效果时不自动播放，展开也不做翻盖动画。
