### 看得到、并且做进页面的

黑底。左上两行字：`Research.`，下一行斜体 `Pacing the frontier.`。中间是一颗由圆堆积成的分形球，圆边是细点，球外有两圈更淡的点状环。球本身不旋转，也不往某个圆里放大。

三个项目写在大圆里，高亮是一块带色边和颗粒的液态光斑，会在它们之间流过去。光斑可以同时拉出两块，旧的一块淡掉：

- `hamr` 在左上，冷色（青到品红），字前有一个十字标记。
- `flokr` 在右侧，暖色（黄到品红）。
- `evolve` 在下方，冷色，字前是四个小圆点。

正中还有一个很小的几何标记，原片里它没有被光斑选中，这里也不把它当成第四个项目。

原片是光斑自己在这三个名字之间循环。页面沿用这个循环；指针或键盘改到另一个项目时，光斑改道流过去。没有项目详情页，也没有点进圆里再展开一层——原片没出现这些。

系统开启减少动态效果时，停在 `hamr` 上，切换是瞬间的，不再自动游走。
