## 复刻说明

自包含单文件，无外链。原帖正文只有 “Upload. #b3d”，没有代码、许可证或仓库链接。页面不嵌原视频、截图或作者标识。环片、地面和光都是当场用 WebGL 画的。

对照的是原帖 3 秒画面（960×720、30fps）。暗场里一叠水平环片收成球体，片与片之间有暗缝。每 1.5 秒一轮，视频里连着两轮：

- 收拢时接近哑光黑，只有顶面和边缘一点轮廓光。
- 从底部开始层间撑开，层缘向外鼓成波纹，材质变成蓝紫自发光，地面出现蓝光。
- 亮起约到一轮的六成时铺满，随后底部先落回去，波纹和发光再逐层收回。

地面是暗的反光平面，带极细网格。亮的时候能看到一层很弱的倒影和脚下的光晕。相机会极慢地挪一点；窄屏会把整组缩进画面。

系统开启减少动态效果时，停在收拢的成型帧，不再循环。
