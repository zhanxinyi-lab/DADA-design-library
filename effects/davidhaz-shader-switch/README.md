## 复刻说明

自包含单文件，无外链。clean-room：只对照约 8 秒预览和同目录静帧里看得到的画面自己写，没有打开或拷贝 canvasui.dev 的源码。

画面是一块近黑圆角面板。顶部是 WebGL / WebGPU 胶囊，选中项是浅一档的内芯和白字。下面是等宽代码，行号更暗，静止时几乎是灰白字，没有彩色语法主题。

点另一侧时胶囊立刻换过去，代码不硬切：先整体发青，红蓝通道错开，若干行横向错位，靠右的字被符号换成残影；接着这些乱字收回去，写成另一套着色器。WebGL 是一段 GLSL ES 300 的色差分量采样，WebGPU 是同一件事的 WGSL。两段示例都是按预览里能读清的结构重写的，用来看切换，不是原站文件。

打开后会自己来回切几次，方便看故障。点过任意一侧后改为只跟手动选择。系统开启减少动态效果时不自动播放，切换也直接换字。
