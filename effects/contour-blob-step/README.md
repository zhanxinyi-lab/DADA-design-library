## 复刻说明

自包含单文件，Canvas 2D，无外链。对照的是素材包里的 `preview.mp4`：720×540，约 5.2 秒。

只复刻切换项目：一颗自己画的等高线球从圆球收成竖向薄片，再胀成另一套条纹。旁边的项目名跟着同一段进度换，不跳变。页面用中性占位名，不写原站人名、客户名，也不用原站纹样。

点球体到下一项，或点左侧项目名直接去那一项。方向键、Home、End 走的是同一段进度。焦点环看得见。系统开启减少动态效果时，取消待执行的帧，直接停在目标形态并同步画完，不为这次切换申请动画帧。关掉减少动态后也按当前形态同步再画一次，不另开动画帧。窄到 320 宽时不横向溢出。
