### 看得到、并且做进页面的

- 顶栏三列固定为 `TEA DIAL` / 水温 / `D02`，下面的小字是 `SUBJECT`、`WATER`、`REF.`。`TEA DIAL` 和 `D02` 全程不变。
- 圆形金属旋钮。红色刻度线绕圆心转动，0° 在正上方、顺时针为正。抽帧里目标温度和角度约成 `温度 = 80 + 角度 / 6.7`。看清的目标温度最低 63°、最高 100°。
- 三个预设写在旋钮周围：`GREEN 80°`、`OOLONG 90°`、`BLACK 100°`。不在加热时，圆心显示目标温度和离它最近的预设名。红点只在目标正好落在 80、90 或 100 时亮起。
- 水温一开始是 21°C。转动旋钮只改目标，不改水温。28.5 秒时圆心已是 `100° BLACK`，顶栏水温仍是 90°C，所以加热不是跟着旋钮立刻发生的。
- `HEAT` 是单独一枚圆形按钮。按下后按钮变红，顶栏水温和圆心一起上升，圆心改显示当前水温加 `HEAT`，红刻度仍停在目标上，目标预设的红点仍亮。水温到达目标后，按钮熄灭，圆心回到目标温度和茶名。
- 片中水温只升不降。目标不高于当前水温时，再按 `HEAT` 没有反应。

### 操作

原片里没有鼠标指针、手指或键盘。页面上能操作的就是画面里那两个控件：

- 鼠标或触控按住旋钮拖动，改变目标温度。
- 点击 `HEAT` 开始加热。
- 键盘是给这两个控件用的，不是片中出现过的操作：旋钮获得焦点后，方向键加减 1°，Shift 或 PageUp / PageDown 加减 5°，Home / End 到 63° / 100°；`HEAT` 可用 Enter 或空格。

窄屏时预设名称改到旋钮下方，避免和旋钮重叠。系统开启减少动态效果时，按 `HEAT` 会直接把水温设成目标，不播放上升过程。
