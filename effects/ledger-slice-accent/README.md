## 复刻说明

自包含单文件，无外链。对照的是素材目录里的 `preview.mp4`：720×406、30 帧/秒、240 帧、8.0 秒。画面是一页角色选择。大约 4.0 秒、5.8 秒、6.7 秒和 7.6 秒各切一次：右侧卡片换成另一个角色时，整页强调色和中间那条斜切色面一起变，红、蓝、绿、琥珀都会出现。色面是一条上右下左的斜带，人在带上交叉淡出。

这里只复刻这一下切换。四个角色、名字和标志都是另画的几何人，不是原片里的人设，页面上也不写原片的栏目标。

点右侧卡片，或把焦点放进卡片后用方向键、Home、End 切换。焦点用强调色描边，选中项另有一条色边。系统开启减少动态效果时，强调色直接落到目标色，斜切面在同一次绘制里改完，不排动画帧。窄屏改成上下排列，320 宽不横向溢出。
