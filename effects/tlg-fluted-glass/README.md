`code/index.html` 是单文件：棱纹着色器和交互逻辑移植自上游 v2.0.0 的 MIT 源码，渲染从 Three.js 改成原生 WebGL，断网也能打开。页面可调棱纹数量、旋转、运动强度、叠层和交互方式（鼠标、滚动、静止）。画面纹理由页面自己画，不使用上游示例图。在自己的项目里用时，可以照上游说明接图片和 Three.js。
