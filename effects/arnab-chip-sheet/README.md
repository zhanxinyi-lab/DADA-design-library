## 复刻说明

自包含单文件，无外链。对照的是素材包里的 `preview.mp4`：实测 8.0 秒、720×406、30 帧，不是清单里写的 22 秒。

只复刻这一下：点筛选钮，筛选条从这颗钮横向展开（排序、配送、到达时间）；再点排序，面板从这颗芯片长出来；选完后面板折回条上，已选项留在芯片里。列表是自己的占位商品，没有原站产品图、手机外框或原文案。

键盘可以打开、选择、关闭，焦点环始终看得见。系统开启减少动态效果时，展开和折回都当场停在终态，同一次操作里同步画完，不申请动画帧。窄到 320 宽时不横向溢出。
