## 复刻说明

自包含单文件，无外链，也没有使用 Three.js。这不是 Water Pro 的源码、贴图或原片画面，只按看得到的运动自己写了一个水面。

站点上的全片 `video.mp4`（台账约 84.5 秒）是 404。对照的是 8 秒预览、`poster0.jpg` 和 `img1.jpg`：冷色天空在上，青绿色的水在下，地平线附近有移动的太阳碎高光，中景带一点橄榄色岸线，构图会慢慢偏转。

改脚本顶部 `BRAND.title` 和 `BRAND.palettes` 即可换品牌名与三套场景配色。拖拽改变视线；右下角「配色」在三套颜色之间切换。系统开启减少动态效果时停在一张定格，只在拖拽、改配色或改变窗口大小时重画。
