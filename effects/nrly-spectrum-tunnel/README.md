## 复刻说明

自包含单文件，无外链。作者没有给出可再分发许可。这里没有使用原站脚本、着色器、字体、图片或音轨，只对照约 28 秒预览和 [线上页面](https://spectrum.nrly.fun) 上看得到的行为，自己写了一个 clean-room。

画面是全屏柔和渐变洞穴：色块像雾一样向一个发亮的中心流，不是硬边几何隧道。打开就在动。指针移动会改变流向；点击会从指针处发出一圈脉冲。

状态大约每 36 秒切换，颜色在约 2 秒内过渡。名字只用看得到的：INTO THE ABYSS、IRIDESCENT MIST、SUNRISE、SEA DRIFT、AURORA BOREALIS、SOLAR FLARE、PEACH NEBULA，然后回到开头。PEACH NEBULA 只在预览的 NEXT UP 里出现，停留画面不在这 28 秒里，配色顺着太阳闪焰末尾的桃色和洋红延续。28 秒预览里几次切换靠得更近，像一段剪过的录像；倒计时按线上打开时读到的间隔。

声音默认关。打开后用 Web Audio 自己合成低鸣，点击有一声短促脉冲，没有音频文件。

把图片拖进页面会采样出一组新颜色，当前状态改成 SAMPLED，并出现这句提示：DROP AN IMAGE TO SAMPLE A NEW STATE。右下角是 CLEAN-ROOM STUDY，不署原作者的名字。

系统开启减少动态效果时，时间停住，只在改窗口、点按或拖入图片时重画。
