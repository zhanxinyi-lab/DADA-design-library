## 复刻说明

实现说明：当前代码是基于 Canvas 2D（`canvas.getContext('2d')`）的视觉复刻，并非 WebGL shader；标题中的“shader”沿用素材名称。

自包含单文件。修改脚本顶部 `const BRAND` 可更换品牌名与背景、正反面颜色。鼠标移动可驱动局部反光；桌面拖拽或触屏上滑翻面、下滑复位，也可用「翻面」「复位」按钮（Tab 聚焦，Enter 或空格操作）。每片使用带切角的金属面与可见倒角，高光会扫过片面；翻面时各片略有错相，能看到连续翻转而非圆点缩放。启用 `prefers-reduced-motion` 时停在静帧，只在交互时重绘。点阵会适配视口，极端长宽比下自动调整网格，始终不超过 1200 片。无外链。
