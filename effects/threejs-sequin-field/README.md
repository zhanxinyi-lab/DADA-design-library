## 复刻说明

自包含单文件。改脚本顶部 `const BRAND` 即可换品牌名、颜色、文案/条目。鼠标移动可驱动高光；桌面拖拽或触屏上滑翻面、下滑复位；也可用「翻面」「复位」按钮（Tab 聚焦，Enter 或空格操作）。启用 `prefers-reduced-motion` 时停在静帧，只在交互时重绘。点阵按视口长宽比铺满画布，并将点数限制在 4800 以内。无外链。
