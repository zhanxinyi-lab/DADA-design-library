# 更新记录

## 1.0.5 — 2026-11-09
- 针对线上视觉反馈强化单片翻面可读性：加大每片可见面比例与切角，增加独立亮/暗反射面和明确边缘厚度，拉开正反面色阶；片间错相更明显。保留 1200 片上限、键盘/触控和减少动态效果行为。

## 1.0.4 — 2026-11-06
- 按用户反馈强化单片亮片质感：改为带切角与明暗倒角的独立金属片，明确显示正反面、翻转边缘、方向性高光和细碎闪光；翻面过程加入轻微错相，避免整片像同步缩放的点阵。
- 提高背景与银色亮片的明暗反差；将复杂单片渲染的网格上限从 4800 降到 1200，控制浏览器绘制负载；保留键盘按钮、触控/拖拽、减少动态效果与响应式布局。

## 1.0.3 — 2026-11-06
- 修正极端窄高视口下网格缩减的点数边界；保证点数不超过 4800，并让椭圆网格在非方形单元中仍覆盖画布。
- 明确说明该效果的当前实现是 Canvas 2D 视觉复刻，而非 WebGL shader。

## 1.0.2 — 2026-11-06
- 尊重 `prefers-reduced-motion`，静止时不持续请求动画帧；增加键盘可操作的翻面 / 复位按钮，并确保手势只追踪一个指针。
- 预生成亮片色阶、减少逐点混色分配，并将点阵限制在 4800 点以内。

## 1.0.1 — 2026-11-06
- 对齐原作的上滑翻面、下滑复位交互，增加点阵密度并为亮片补上边缘与高光层。
- 按视口长宽比计算点阵行数，避免手机竖屏出现大块空白。

## 1.0.0 — 2026-11-02
- 首次收录（AI 复刻）。
