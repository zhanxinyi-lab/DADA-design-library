## 复刻说明

对照原帖和完整预览。原帖是 GSAP 的 Site of the Day：Tira le Chat，作者 Daniel Kiss，写明用了 ScrollTrigger、ScrollSmoother、DrawSVG、SplitText，以及 SVG / WebGL。预览文件 30 帧/秒、240 帧，共 8 秒；站点上的 `preview.mp4` 与这条本地副本大小一致。

8 秒里能看清的滚动是这几拍：开场剪贴人像换姿势，黑夹板从画面下方升上来，大字换成下一句，夹板再向右翻开，墙上冒出小贴纸，顶栏的下划线跟着移到后面的一项。开头那条提示条会自己消失，不算滚动，这里不收。WebGL 在这 8 秒里看不出单独画面，所以没有另做三维场景，翻板用的是平滑滚动和 CSS 立体变换。

原站几乎抽不到许可说明。不声称有许可，也不复制原站代码、照片、字标或文案。人像、夹板和句子都是新的。

可以滚动。没有减少动态效果、也没有操作时，会按上面的顺序自己走一遍。滚轮、触摸或方向键会接手。减少动态效果时停在开场，滚动直接到位，不做平滑补间。
