## 复刻说明

自包含单文件，无外链。细指针以按钮边缘为基准：130px 外不显示；走近后先出现一圈原创接近环，越近越清楚，填充仍保持空闲色。悬停或键盘焦点时，浅色填充从下往上擦过胶囊，并在胶囊内溅出原创色块。

参考演示的许可未核验，因此没有复制其代码、粒子形状、配色或文案。色块只用方形和短条。

粗指针不显示接近环，也不绘制粒子，只保留按下态。键盘使用真实按钮，Tab 到达后出现与悬停一致的擦除和粒子，Enter 或 Space 可触发。系统开启减少动态效果时不显示环和粒子，填充瞬时切换。
