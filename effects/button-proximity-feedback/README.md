## 复刻说明

自包含单文件，无外链、无粒子层。行为参考是细指针靠近按钮时先有接近反馈，悬停或键盘焦点再切换按钮本体。参考演示的许可未核验，因此没有复制其代码、粒子、配色或文案。

粗指针不显示接近环，只保留按下态。键盘使用真实按钮，Tab 到达后出现与悬停一致的填充态，Enter 或 Space 可触发。系统开启减少动态效果时不显示接近环，状态立即切换。
