## 复刻说明

自包含单文件，无外链。细指针以按钮边缘为基准：130px 外不显示；进入外圈后开始绘制粒子，但在落到 65px 内圈之前保持隐藏；65px 内粒子以原创色块淡入，按钮填充仍保持空闲色。悬停或键盘焦点时，浅色填充从下往上擦过胶囊，粒子加速并留在胶囊内。

参考演示的许可未核验，因此没有复制其代码、粒子形状、配色或文案。色块只用方形和短条。

粗指针不绘制粒子，只保留按下态。键盘使用真实按钮，Tab 到达后出现与悬停一致的擦除结果，Enter 或 Space 可触发。系统开启减少动态效果时不绘制粒子，填充瞬时切换。
