## 复刻说明

自包含单文件，无外链，也不引用外部字体或图片。

对照的是仓库里的原帖 `preview.mp4`：720×568、30fps、实测 8.00 秒。同目录原来的 `preview.webm` 是 480×378、60fps、6.00 秒，和 mp4 不是同一段时长。两条都是原工具的屏幕录像：从空光标打出句子，当前词被红角框住，框上有坐标，光标右侧散开点阵，新打的字带着红绿重影再落定。`poster0.jpg` 是打到半句时的点阵，`img1.jpg` 是选中一个词后的红框。原句和工具名只作对照，页面里不出现。

`preview.webm` 已换成打开 `code/index.html` 后自己录的屏，5.60 秒、1280×720，不是把原帖 mp4 重编码。画面里先打出 “and a soft trail”，再拖选 “short”，接着用 Shift 和方向键把选区扩到 “phrase”。海报和 `preview.mp4` 仍是原帖参考。`duration_s` 记这条自录的整秒时长 6。

页面是一块可写的编辑区。输入、指针和键盘改的是同一个光标和选区：打字、粘贴、方向键、Shift 扩展、点击和拖选，红角框都会滑到同一段文字上。正在写的词用紧框和坐标，它和前一个词共用一圈更大的角框；光标右边的点阵和字上的重影随这次输入淡出。系统开启减少动态效果时，文字、框和坐标直接停在新位置，不生成粒子，也不再排动画帧。
