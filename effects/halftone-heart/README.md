## 复刻说明

自包含单文件，无外链。对照原帖画面自己画，没有搬 WHOOP、日期、HRV 读数或解剖坐标。

`preview.mp4` 是原帖屏录，只作参考，清单里的 `video` 仍指向它。`preview.webm` 已换成这一页自己的录屏（480×600，实测 6.8 秒）：指针转视角、滑杆改心率，并切过蓝紫、冰和烬。

近黑网格上是一颗半调点阵心脏。点的大小和颜色跟着受光变化，亮处点大、接近预设的浅色，暗处点小、偏预设的深色。指针在画面上移动时改变同一套状态里的视角；滑杆、上下方向键和 `+`/`-` 改变心率（42–168 BPM）。心跳相位按当前 BPM 连续累加，波形是一圈傅里叶级数，换速时不会跳到另一拍。底部细线用的是同一个相位。四套颜色：蓝紫、冰、烬、信号，数字键 1–4 也能换。

系统开启减少动态效果时，停在舒张那一帧，不排动画帧。指针和心率仍会立刻重画当前目标，不做过渡。
