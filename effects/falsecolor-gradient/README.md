## 原文

Studio Gruhl × Rerun 品牌识别 — “See what robots see”。

条目说明：用机器视觉的 Jet/Turbo 伪彩色图做品牌渐变，迪厅般的高饱和渐变加螺栓头几何字标动效；可复刻成可换字标与配色的伪彩渐变品牌动效。

## 复刻说明

只抽了预览视频左侧那一层：整面伪彩色带顺着色谱滑动，映射中心一变，红、黄、绿、蓝就整幅换位。右侧白、暖灰、黑的色板，以及海报里的产品卡片，都没有做。

字标是新画的几何字母，只借用「螺栓头 + 一字槽」这种结构。不搬原品牌名、原字标和作者署名，页面里也不出现这些名字。没有外链。

指针在背景上左右移动，直接改映射中心；移回去，颜色回到刚才的位置。Jet / Turbo 两个按钮切换色表。左、上方向键回到 Jet，右、下方向键到 Turbo，和按钮是同一个参数，可以来回切。

系统开了「减少动态效果」时，色表直接落到目标，不再排过渡帧。
