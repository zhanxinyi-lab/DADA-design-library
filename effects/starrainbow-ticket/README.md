## 复刻说明

自包含单文件，无外链，也不嵌入原片。对照的是原帖 1920×1080、2.9 秒成片（30fps），不是站点上那条 76KB 的低清预览。作者在 acreamstudio.com 把这件个人作品称为 StarRainbow Ticket，并说明画的是全息卡的虹彩，以及流体渐变随着角度不断换位。

浅色画布中央是一块边缘发虚的圆角色面。左半以蓝色为主，右侧偏紫，中间偏右有一条青色流光，并带一小块品红。色面在 2.9 秒里循环：大约 0.7 秒和 1.8 秒各向中间收一次，然后再铺开。平均色相只在蓝紫之间小幅漂移。

能稳定读出的字：

- 上方短词。0.0 秒拆开是 C、O、T；0.8 秒连成 COTA。页面按 COTA 排。
- StarRainbow
- Start Time: 8:00 A.M.
- End Time: 11:00 A.M.

左下还有一行很小的票号，逐帧识别不稳定，所以不编一串假数字。右侧两个小亮点会被识别器读成 “Object”，位置和大小都不像正文，没有画成标签。成片里没有光标，也没有点击，所以色带自己循环，不另做悬停剧本。

系统开启减少动态效果时停在 0 秒那一帧（字最清楚）。页面上的暂停只控制这段循环。
