## 复刻说明

自包含单文件，无外链。不嵌原视频、海报或截图，也不使用原界面里的产品名、客户名和原句。

`poster0.jpg` 仍是原帖海报。`video`（`preview.mp4`）是原帖参考片，实测 8.0 秒、720×540、30 帧/秒。登记里原先写的 14 秒和这条片子不符。参考片只作对照：一块看板卡片里，时间范围从「月」滑到「周」，摘要数字和柱形跟着换，不是整页硬切。

`preview.webm` 是打开 `code/index.html` 后自己录的，不是把原帖片子重编码。1280×720、8.0 秒。画面从「本月」开始，依次点到「本周」「全部」，再回到「本月」。

页面只留这块卡片上的切换。点「本周 / 本月 / 全部」、用手指点同一组按钮，或在按钮上按左右方向键、Home、End，都走同一段进度：滑块、数字、柱高和说明一起过渡。过渡中途再切，从当前数值接着走，不跳回起点。系统开启减少动态效果时直接停在目标范围，不排动画帧。320 和 390 宽没有横向滚动。
