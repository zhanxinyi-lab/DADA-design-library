## 复刻说明

自包含单文件，无外链。对照的是站点预览 `preview.mp4`（720×900，约 8 秒）和登记说明。原帖正文只有 “App design is all about seamless transition.”，没有代码、许可证或仓库链接。页面不嵌原视频、截图、商标或原片里的 3D 角色。

预览里能看清的节奏：

- 开场停在 OKAY。底部是一排扇形心情卡，旁边露出相邻的颜色，中间有一颗白色圆钮。
- 手指拖动时，卡、大字、背景和表情是同一进度，不是四个互不相关的按钮。大字会错开并变模糊，大约半秒到八成秒后落定。
- 顺序是 LOW、OKAY、GOOD、GREAT，首尾相接。OKAY 是平嘴，GOOD 是轻微笑，GREAT 是大笑，LOW 是皱眉。
- 停稳时出现 “Tap the mood to select it”。拖动中提示隐去。
- 这 8 秒里没有确认页。登记说明要求最后落到 “Noted, gently.”，所以点当前这张卡，或在键盘上按 Enter / 空格，会用同一种过渡进入确认页。返回再改。

脸上没有眼镜，也没有原片那只 3D 小人。这里是自己画的扁平面孔：圆脸、圆眼睛、一张嘴。颜色只沿用画面里能读到的金、绿、珊瑚、蓝。

左右方向键移动当前项，当前卡有深色焦点环。系统开启减少动态效果时直接换到对应心情，不做位移、模糊或淡入淡出。窄屏时手机框缩进窗口，很窄时去掉外框铺满。
