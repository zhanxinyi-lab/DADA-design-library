## 复刻说明

自包含单文件。改脚本顶部 `const BRAND` 可换产品名、工作区名和地址。无外链，无图片，无字体文件。

对照原帖全文和 27.8 秒原片（库内 8 秒预览只覆盖第一步）：

- 四步都在同一页。顶部四段线路标出还剩几步：还停在当前步时这一段保持黑色；点继续、跳过或创建并进入下一步后，上一步才变绿；第四步做完显示 All set，四段都变绿。
- 第一步点工具，卡片先变成 Waiting，右侧工具列表立刻长出这一行；连上之后活动流再长出一行，Continue 才可点。
- 第二步勾选队友。未发送时右下角是 “N to invite”；发送后长出邀请记录和人数。可以跳过。
- 第三步选一个模板再建代理，右侧代理列表和活动流长出对应项。模板上的 “n of n connected” 跟第一步实际连上的工具走。
- 第四步右侧长出任务卡片，条目逐条打勾，最后长出结果条。点 Open Detent 或左上角标志从头再走，不离开页面。
