## 复刻说明

自包含单文件，无外链。不搬原帖家具贴图、屏幕内容和品牌。

原帖是可在浏览器里走动的公寓，顶栏能点 Tour、Photo、Walk、Lighting only、Wireframe，以及 Low sun、Morning、Day、Evening、Night。这次不做整栋公寓，也不做走动。只留一间固定房间，在白天、傍晚、线框之间切换。

`poster0.jpg` 和 `preview.mp4` 是原帖素材。mp4 实测 720×406、30fps、240 帧、8.0 秒，不是条目里原来写的 60 秒。这 8 秒是镜头推近桌面，顶栏停在 Tour / Low sun，没有点到 Day、Evening 或 Wireframe。它们只作对照。

`preview.webm` 是打开 `code/index.html` 后自己录的屏：1280×720、vp9、25fps、200 帧、8.0 秒。从白天切到傍晚，再切到线框，最后回到白天。录的是这一页，不是原帖成片的重编码。

三个按钮和键盘方向键、1 / 2 / 3 改的是同一套光照状态（冷暖、太阳高度、线框比例、台灯）。切换用约 880ms 平滑过渡，不硬切。系统开启减少动态效果时，直接停在目标光照，不排动画帧。
