## 复刻说明

自包含单页，浅色空底。画面中间一把自己画的短枪，枪口跟着指针转。按住鼠标主键后，枪口连续喷出自己画的绿色纸币；纸币在飞出去时绕横轴和竖轴翻转，侧面会薄成一条。松开、指针取消、指针移出窗口、指针捕获被释放或窗口失焦，都会停止喷射；这些停止可以重复触发。已经飞出的纸币会自己离开画面。

对照的是本地预览片 `preview.mp4`：720×720、30fps、240 帧，实测 8.0 秒。条目里写的 28 秒和这条文件对不上。片中能看到按住后枪口撒出带透视翻转的纸币，松开后不再继续喷。

不画对方的页面、浏览器窗框、标题或按钮，枪身上也不放 craft 标志，纸币上不写 Unlimited tokens。原帖没有附代码或许可证，所以枪和纸币都是新画的简单形状。

系统开启减少动态效果时，按住只把枪转到当前指针方向并停住，不喷纸币，也不预约动画帧。空格按住与鼠标主键相同；按键重复不会重新开始。整页可以聚焦，键盘聚焦时有深绿色焦点框。正在喷时 `aria-pressed` 为 true，状态文字是「正在喷」；停喷后是 false 和「已停止」。

窄屏把枪限制在视口内，纸币飞出画面时被裁掉。320 宽不出现横向滚动。
