自包含单文件，Canvas 2D，无外链。对照原帖约 54.7 秒视频（576×360 抽帧）和作者正文：靛蓝底上的银色粒子先构成一条横向游动的锦鲤，随滚动散开，再聚成左侧的瓶和右侧的杯。往回滚会回到锦鲤。站点 `preview.mp4` 只有约 8 秒，只覆盖游动，看不到重组。

页面不使用原品牌字标、酒造店名、广告句，也不使用产品静帧。瓶和杯是自绘剪影。系统开启减少动态效果时不自动游动，用「锦鲤」「瓶与杯」切换。
