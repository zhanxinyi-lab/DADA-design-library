## 复刻说明

自包含单文件，无外链。原帖正文是 “make it pop: 002”，没有代码、字体或许可证。这里不嵌入原视频，也不搬浏览器窗框、地址栏或其它图形。字用系统字体（Arial Black 及其回退）。

对照的是本地预览片 `preview.mp4`：720×720、30fps、240 帧，约 8 秒。登记里写的约 18 秒和这条文件对不上。

片头约 0.5 秒是黑场。接着两行字一起从更低、更小、更靠中间的位置落到终态，大约 0.4 秒落定，曲线是先快后慢，终态前没有再冲过静止位置。上面一行抬得更高（约 0.55 个字号），下面一行大约一半。左到右只差一帧上下，所以做成很短的依次延迟，读起来是逐个弹起，而不是九个字母各弹一次。

“make”和“it”是白字。“pop”内部的彩虹按屏幕位置铺，不是按字母序号各给一块纯色。指针靠近时，大约 0.05 到 0.20 个屏高的范围内颜色绕着指针转，最近的笔画会亮一点；超出这段就回到原来的流动，不会整段一起变色。指针离开后搅动退去，流动还在。

系统开启减少动态效果时，直接停在终态的一帧，不再弹起，指针也不再搅动。颜色跟随只认指针；键盘可以聚焦「重放」，再看一次弹起。

窄屏把整组字缩进视口，320 和 390 宽都不溢出。
