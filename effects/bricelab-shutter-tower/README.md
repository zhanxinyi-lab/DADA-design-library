## 复刻说明

自包含单文件，无外链。楼、窗和百叶都是 Canvas 2D 自绘体块，不使用原片照片、原站模型或贴图。

站点预览 `preview.mp4` 实测 8.0 秒、720×720、30fps（登记写约 14 秒，与文件不符）。画面是黄昏里一座转角塔楼：窄的一侧和宽的一侧同时可见，深色窗框里是钢制横百叶。指针靠近时，百叶按窗口成片翻开，近处先动、开得更大，远处后动、角度更小，缝里透出暖黄灯光；离开后按同样的先后合上。

原帖写的是 three.js + WebGPU。这里只用平面几何做出翻开，不声称使用 WebGPU 或 TSL。触摸拖动和鼠标一样带动百叶。系统开启减少动态效果时，停在半开的一帧，不跟指针，也不排动画帧。
