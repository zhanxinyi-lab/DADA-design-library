## 复刻说明

自包含单文件，无外链。只做原视频第 3 段：浅蓝底上的圆角厚块，左右各有一个内凹缺口，块内洋红、紫、青颗粒虹彩流动，边缘有高光。厚块会缓慢缩放、收腰并轻轻扭转，不是静止色块。

缺口深浅、厚度和呼吸节奏按这一段画面判断后自己写。没有使用视频、字体或品牌素材。同条里的浮动卡、三联海报和轮播没有做进来。

系统开启减少动态效果时停掉动画循环，只画一帧完整造型；窗口尺寸或该项设置变化时再画一次。
