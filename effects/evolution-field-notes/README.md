## 复刻说明

参考原帖里这一套交互：一页手骨可以拖，拖向不同位置时同一套骨头平滑变成翅膀或鱼鳍，中间停住能看见过渡；笔记可以点击或拖着翻页；课程是卷轴，能展开，也能再卷回去。

没有搬原站、品牌、课文、测量数据和插画。页面上的句子是按「同源肢骨」重写的。骨架用代码画，拓扑始终是一根上臂骨、两根前臂骨、五指，靠位置插值变形，不换模型。原帖里还有马腿、蜗牛测量、胚胎点选等其他课，这里没有做。

### 操作

- 拖右页上的圆点，或拖骨头本身。圆点在「手 / 翅膀 / 鱼鳍」三个端点围成的范围里移动，骨头按权重插值，松手才靠向最近的端点。
- 点这三个名字也会过去。圆点获得焦点后，方向键一次走一小段，能停在中间形态。
- 右侧页角点击或往左拖，翻到下一页；左侧页角往右拖，或「上一页」，翻回去。左右方向键、PageUp / PageDown 同样翻页（焦点在圆点上时，方向键改管变形）。
- 左侧课程卷轴：点击、或焦点在上面时按回车 / 空格，展开或卷回。展开另一课会翻到那一页。
- 触控走同一套指针事件。
- 系统开启减少动态效果时，变形直接跳到当前权重，松手直接落到端点；翻页不转角度，没有弧线。
