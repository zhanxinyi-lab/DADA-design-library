## 复刻说明

自包含首屏极光光柱与加载转场效果。修改代码顶部 `const BRAND` 即可替换品牌名称、颜色与文案。

## 1.1.0 新增

- `BRAND.intro`：默认 `'rise'`，黑场里颜色跟着节拍（`BRAND.bpm`）一涌一停地从下往上蔓延，前沿是柔和起伏的边；改成 `'loader'` 恢复原版 %0→%100 圆环加载。
- `BRAND.flow`：光柱里的颜色按节拍上下起伏，相邻光柱一起走，每两拍换一次形状；开场时流得更快更大，3~4 秒后回到常速。`false` 恢复原版。
- 来源：HARKEN 开场动画项目里调出来的背景律动，回流到这里。
