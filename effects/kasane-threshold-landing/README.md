## 复刻说明

自包含单文件，无外链。对照原帖 8 秒预览里能读到的序章，以及现站开场的操作，不使用原站模型、贴图或角色立绘。

开场是一段程序化夜林：石径、树、花瓣、灯笼和一道门槛。鼠标（或触控拖动）左右张望；页面原生滚动把镜头推向门槛，文案从 “Some doors remember you.” 过渡到 “Even silence has a heartbeat.”，底部有阶段和进度。可跳过序章。声音默认关闭，打开后只在本机合成一段很轻的双音，不加载音频文件。

滚过序章后是落地页骨架：世界、三个名目、三式、三个地区入口，以及在本地画好再下载的几何印记。长传记、对白和原站插画没有照搬。改脚本顶部 `BRAND.name` 可换品牌名；阈值、灯笼色和印记字形也在同一处。

系统开启减少动态效果，或页脚切到 “Motion: still” 时，花瓣和呼吸停住，滚动仍可前进，跳转不再平滑。
