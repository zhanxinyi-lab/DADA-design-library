## 复刻说明

原帖是竖屏网页里的高斯溅射场景：人物在场景中走动，作者说明用了 MediaPipe、Three.js、Spark.js，并用 WorldLabs 从单张场景生成医院 splat，再用 Radix 在 WebGPU 上渲染，手机可借陀螺仪张望。帖内没有代码、演示页或 splat 文件。

本目录是自包含的 Canvas 2D 复刻，不加载上述库，也不使用原医院场景、原角色或任何原片画面。场景改成开放的暖色石柱长廊，散步者是没有五官的原创披风软点人。步态是程序化的，用来代替无法内嵌的 MediaPipe 姿态。桌面用指针或按钮张望，手机可启用陀螺仪。`prefers-reduced-motion` 时停在一步静帧，只在张望时重绘。无外链。
