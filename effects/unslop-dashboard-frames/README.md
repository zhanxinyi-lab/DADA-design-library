## 复刻说明

自包含单文件，无外链字体和图片。原帖只有一张图，没有视频。站点海报是 [heydamir/unslop](https://github.com/heydamir/unslop) README 的截图，主视觉是 `story-dashboard-frames.webp`：八帧、约 10 秒，一块 vibecoded 仪表盘在原地洗掉渣感。仓库以 CC BY 4.0 授权改编，本页署名 Damir Sokolovsky，并链回该仓库。

正方形画面裁在侧栏和第一屏卡片上，对应这八帧，而不是整页售后稿。洗之前的文案、emoji、紫渐变和参差间距来自同仓库 `examples/dashboard.html`。洗之后的用词按故事帧最后一格读到的结果：`Ember`、`Search`、`October 2026`、`Paid this month`、`$48,210`、`+12% vs last month`、`Overdue`、`07`、`3 fewer`、`Revenue`、`$124,860`。

播放顺序按八帧的像素差：先出红色测量线，再把导航间距拉齐，红线转白，然后颜色从左上向右下洗成石墨，emoji 和发光褪掉，最后文案逐字换掉。系统开启减少动态效果时停在洗完的一帧，用「下一步」切换。
