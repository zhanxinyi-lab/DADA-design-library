## 复刻说明

参考可用原视频片段的「LIQUID」段：黑场里一道细液面线 → 中间鼓起透明圆顶、拉出脖子后脱离成大泡泡 → 悬浮晃动、吸进两颗小水珠 → 一缩分裂成一串水珠 → 先融成胖胖的软字，再收紧成透明玻璃字。可核对的 9 秒片段结束时仍是玻璃字；片段之外的实心白字定版没有可核对的视频证据，不纳入本版本。

纯 WebGL 着色器，无外部依赖。默认字是 DADA，画面按比例完整放进窗口（不裁边）。改代码顶部 `const BRAND`：`word` 换字、`font` 换字体、`rim` 换边缘虹彩倾向色、`glowA / glowB` 换背景柔光色，`loop` 控制是否自动重播。网址加 `?freeze=秒数` 可定格检查某一帧。

原片还有音效、HUD 和其它段落，这里只复刻了泡泡成字这一段。
