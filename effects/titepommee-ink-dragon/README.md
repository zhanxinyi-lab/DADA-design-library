## 复刻说明

自包含单文件。改脚本顶部 `SCROLL` 即可换短句、印章用字、火色和水彩。指针移动时火龙跟着走，走过的墨迹绽成水彩；停住并按住，或按住空格 / 回车，会喷火烧穿纸面。方向键也能引导。触屏拖动只接管纸面，纸面外仍可滚动。尊重减少动态效果偏好。

对照过的只有这些：原帖说明、站点 `poster0.jpg` / `img1.jpg` / 8 秒 `preview.mp4`，以及作者公开页「Huolong — Ink and Colour」里能核对的分层和操作。纸面是暖米色，墨色只占很小一块，按住后前景层会出现暖橙色火痕。页上的提示是引导火龙走过纸面，按住才喷火。公开仓库没有许可证，所以这里不使用原诗词、原印章、原三维模型和原页面代码；短句、印章和龙都是新画的。
