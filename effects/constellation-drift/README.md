## 复刻说明

自包含单文件，无外链，不使用 GSAP。对照原帖点名的滚动叙事、拆行标题、减少动态、星图和可选声音，以及原帖所链欢迎页上能直接看到的画面。

能核对的部分：

- 深色全屏星图：亮点连成路径，当前一站有圆晕。
- 滚动把叙事从开场推进到六站，再推进到外圈星野。每站换距离词、标题、理由和底色。
- 开场标题拆成两行升起。底部有「往下走」的轨道提示。
- 右上角可以开关一段声音。默认不开。
- 系统开启减少动态效果时，不跟滚动，改用上一站 / 下一站。

站点已发布的 `preview.mp4` 是 8 秒、720×406 的低清录像，能看出画面在切换，但具体字形读不清。`video.mp4` 与 `preview.gif` 返回 404。因此站名、句子、艺人、封面和原站音乐都不用。六站名称、距离词和振荡器音调是自编的，只保留「越走越远、换站换色」这层运动。
