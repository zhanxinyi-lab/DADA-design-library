## 复刻说明

自包含单文件，无外链。clean-room：只对照约 18 秒预览里看得到的画面自己写。没有使用 UIBrik 的组件、着色器、字体或许可证，也不声称获得许可。产品页只当作行为线索。

画面是全屏拱形地平线。暗处是近黑底上的细小暗红圆点，越亮点越大，到橙红带融成光滑光晕，再往下变成近白。左右光晕略高，中间更暗，光晕整体偏低。打开就在缓慢流动，不是静帧。

指针是一盏局部灯：附近网点胀大变亮，走过的地方留一条会淡掉的轨迹。点击从指针处扩出一圈涟漪。上半暗空有一句 “Halftone Horizon”。

系统开启减少动态效果时，地平线不再自己起伏；指针和点击仍然重画。
