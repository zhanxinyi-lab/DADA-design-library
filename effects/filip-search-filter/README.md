## 复刻说明

参考里能看清的是：近黑页面，左右两片细点，中间一条搜索，下面四个带加号的筛选（Section、Site、Style、Text），再往下是浅色圆角结果卡。预览是镜头倾斜掠过，看不清逐字打进去的节拍，4.5 秒之后下半页已经暗到读不出字。逐字过滤、匹配高亮、重排缓动、筛选计数、空结果和键盘，按这条交互来做；四个筛选沿用海报上的分工，写成「区块 / 站点 / 风格 / 文字」。

没有搬的：产品名、顶栏里的第三方标记、原句标题、预览里的网页截图。结果卡是自己的色块和句子。

打开减少动态效果时，结果立刻换到新位置，高亮一次画完，不逐字铺开，也不做入场淡入。
