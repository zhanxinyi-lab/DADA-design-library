## 复刻说明

自包含单文件，无外链，也不使用原站字体、标志或手册正文。

`preview.mp4` 实测 8.0 秒、720×462、30fps（登记写约 20 秒，与文件不符）。同目录的 `preview.webm` 是 6.0 秒、480×308。成片前段是手册阅读页，后段是一块可以缩放的图板，画面里没有搜索小球。封面 `poster0.jpg` / `img1.jpg` 才是一圈可推动的章节小球，中间一条搜索。

这次只复刻封面那两下，文案改成自写的十二条步行笔记：

- 指针拖过小球时给它速度，球自己滑行，彼此会撞开，碰到屏幕边缘会弹回，不是跟着指针瞬移。
- 搜索框里写下词语时，对得上的球被连续拉向搜索框；没对上的留在原来的一圈。回车确认当前结果。
- 键盘可以 Tab 到搜索框再按回车。
- 系统开启减少动态效果时，匹配结果直接摆好，不排动画帧。
- 没有推动、也没有还在滑动或吸合时，停掉 `requestAnimationFrame`。
