## 复刻说明

自包含单文件，无外链，也不使用原站字体、标志或手册正文。

`preview.mp4` 实测 8.0 秒、720×462、30fps（登记写约 20 秒，与文件不符）。同目录的 `preview.webm` 是 6.0 秒、480×308。成片前约 2 秒是手册阅读页在滚动中停住，之后切到一块图板。封面 `poster0.jpg` / `img1.jpg` 才是一圈章节小球，中间一条搜索。封面上的字写着 “PUSH THEM AROUND” 和 “TYPE WHAT YOU WANT”，所以可推动、以及输入后把对得上的球吸向搜索，是封面文字写明的用法，不是另编的玩法。

阅读起伏按成片逐帧量过，不是循环摇摆：

- 正文列大约在 0.6 秒到 1.4 秒还在上下移动，到 1.40 秒垂直位移落到 0。
- 每一行有一点倾斜。屏幕上半行往一个方向，下半行往另一个方向，最上和最下接近平直，相当于视口高度上的一个正弦。
- 滚动还在走时，行的倾角大约到 2.4°。按一行三百像素算，左右两端高低差大约十像素。
- 滚动停住之后，倾角从 1.23 秒的大约 1.8° 掉到 2.10 秒的大约 0.25°，时间常数约 0.30 秒。停住以后不再起伏。

页面对应的参数：滚动速度（像素/秒）除以 200，得到目标倾角，并限制在 ±2.4°。倾角再以 0.30 秒的时间常数跟上这个目标。每一行的转角是这个倾角乘以 `sin(2π × 行中心 / 视口高度)`。速度回到 0 以后，行在大约半秒里躺平，然后停掉动画帧。

小球仍按封面那一圈散点摆。推动时整颗球的速度不超过 240 像素/秒；松手立刻把速度清成 0，只靠回到原位的弹簧收回来，不靠松手后剩下的速度冲出去。对上的球整颗排在搜索面板下方，和面板留出空隙；排不下时画板变高，页面向下滚就能点到。球可以 Tab 聚焦，方向键挪一步，点一下、回车或空格选中；选中和搜索匹配都会反映在按钮的按下状态上。减少动态时不保留惯性。从减少动态切回普通时，先按当前状态画一帧，再交给动画帧。
