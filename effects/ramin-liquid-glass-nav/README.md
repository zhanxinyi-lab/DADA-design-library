## 复刻说明

对照约 8 秒、720×480 的预览自行编写，无外链。浅灰底上是一条圆角导航，标签为 Logo、Branding、UI/UX。一块半透明液态玻璃胶囊停在当前标签上，边缘有轻微彩虹折射和高光，中间的字保持清楚。胶囊滑向下一标签时会先拉长再收回。

预览是贴着胶囊的近景。这里把整条导航放在画面中间，三枚标签一次看全，不画假光标。细指针悬停时胶囊跟着过去，离开后回到当前项；点选、Enter 或 Space 才切换当前项。方向键会切到相邻标签。触控只在点选后移动。系统开启减少动态效果时，胶囊直接到位，高光不再绕着边缘走。系统开启降低透明度时，胶囊改成实底。

这不是 `guanmo-liquid-glass` 的玻璃表面，也不是 `kloss-liquid-glass-type` 的泡泡成字。那两条没有改，也没有搬它们的实现。
