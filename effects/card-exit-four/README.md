## 复刻说明

原帖是四种卡片删除，不是整站。这一页放四张可点的卡片，各自用一种离场：燃烧从落点铺开焦痕和白热边，火焰往上卷并让旁边的卡片晃一下，碎块裂开落下，撕贴纸从一角揭起。卡片离开后，剩下的会补上这个空位。

不搬原品牌、原插画和成片画面。键盘用 Enter 或空格触发。系统开启「减少动态效果」时，卡片直接消失，不播粒子，其余卡片立刻补位。
