## 复刻说明

自包含单文件。浅色整页被切成大模块，缝宽接近格子本身。格子有两种身份：实心字块，或一条编辑索引。字块按像素字拼在同一张网格上，比一屏更大；移动指针，窗口就沿网格换到字的下一块。指着的那一块会让开，露出它自己的编号。点一下可以钉住。

页面上的编号和条目是新写的，不用原站句子和图片。原帖只确认这是在谈网格、构图和运动的互动网页；8 秒预览能看清浅底、宽缝、实心深块和内容格在换位，看不清原站界面文字。

改脚本里的 `WORD` 和 `NAMES` 即可换字和索引。
