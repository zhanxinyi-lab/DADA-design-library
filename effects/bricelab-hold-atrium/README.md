## 复刻说明

自包含单文件，无外链，也不使用原站模型、字体、贴图或界面。

站点已发布的 `preview.mp4` 实测是 8.0 秒、720×720、30fps（目录写的 37 秒与文件不符）。画面从俯视的线框平面开始，相机进入后线框体量升起，再被混凝土、植物和一道竖向水帘盖住。视频后段的站点导航不属于这次入口复刻。

原帖指向 https://webgpu.com/showcase/bricelab-webgpu-concrete-atrium ，在线作品是 https://www.bricelab.dev/ 。公开页面写明按住中央控制才开始构筑，百分比从 0 走起。入口脚本里的时间是：按住 900ms 线性走满；松开后先停 120ms，再用 inOut(2) 在至少 450ms、至多约 1200ms×进度 的时间内回到线框。主键作用在整层入口上，并捕获指针；松开和 pointercancel 都会取消。空格、回车与鼠标主键同等，按键重复不计。系统开启减少动态效果时，一次确认直接到静止的建成画面。

未找到允许使用原站资产的许可证。房间、柱子和水帘都是新的简单几何。这里用 Canvas 2D，不声称使用 WebGPU 或 TSL。Esc 是演示用的额外退出，避免停在建成画面里，不是原站记录到的行为。
