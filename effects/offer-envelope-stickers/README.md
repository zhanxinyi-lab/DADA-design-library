## 复刻说明

自包含单文件，无外链，也不嵌入原片。对照的是素材包里的预览：实测 8.00 秒、720×428、30 帧，不是清单里写的约 17 秒。8 秒里能看完从合上到贴住。

只复刻开信封、贴纸飞出并贴住。牛皮纸袋略斜，开口在右侧。点开或等到自动开始后，袋口先掀开，贴纸再分批沿弧线飞出，不是同时弹出。多数落在袋子四周，两张贴回袋面，一张落到袋子下方。贴住时有一小下回弹。

文案和图形是另画的，没有沿用原品牌名，也没有描原贴纸图案。

点袋子、点「再开一次」，或按 Enter、空格、R，可以再开一次。系统开启减少动态效果时直接显示贴好的终态，不排动画帧。飞出结束后不再请求下一帧。
