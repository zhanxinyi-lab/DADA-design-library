## 复刻说明

对照原帖 1080×1080、约 10.1 秒的成片，以及站点 `/s/rjqagsc0hcqp/assets/2117483764217774204/` 的 poster 和 preview。画面是浅灰底上的墨色软形，不是工具界面。

能核对到的运动：开头左边是两枚分开的竖胶囊，右边是更大的圆角团；大约 1.6 秒后开始胀开；到 4.8–6.4 秒整体向左靠拢并合成一块；8 秒左右重新分开；9.6 秒回到接近开头的位置，然后循环。

这里用四团软边椭圆场做成同一套时序，不嵌原片、不描帖子文案，也不出现 Opus 或 After Effects 的名字和标识。原帖引用的动效指南没有可核对的分镜，不纳入。

纯单文件，无外链。网址加 `?freeze=秒数` 可定格（例如 `?freeze=4.8` 看合成的那一拍）。系统开启减少动态效果时停在开头。
