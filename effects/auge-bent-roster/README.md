## 复刻说明

自包含单文件，无外链。对照的是站点里的 `preview.mp4`：720×540、30 帧/秒、174 帧、约 5.8 秒。页面灰边里是一张圆角卡片。卡片上是一列名单，当前项更大，靠在一块宽画面旁边；画面不是矩形提示框，顶边和底边弯成弧，中间被拉高。切换时这块画面先收成一条扁的弯曲带，宽度先回来，高度再撑开。卡片本身也分成奶油色和黑色，分界是一条向下弯的弧，当前项一换，深浅跟着换。左侧还有一列小预览，贴在同一张面上。

名单、编号和色块都是另写的，不是原片里的客户名或镜头。色块画在本地 canvas 上，再贴到自行细分的曲面上。

鼠标划过某一项，或用 Tab 逐项聚焦，都会浮出同一块曲面。方向键、Home、End 也能换项。系统开启减少动态效果时，名单和曲面直接停在该项的弯曲完成态，不再补间；指针仍会立刻把附近的面拉开，没有过渡。窄屏时曲面改到名单上方，名单整列居中。
