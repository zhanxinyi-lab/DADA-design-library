## 复刻说明

自包含单文件，Canvas 2D，无外链。对照的是素材包里的 `preview.mp4`：实测 720×540、30 帧、240 帧、8.0 秒。

只复刻切换步骤：点右侧步骤时，左边一排试管拧成螺旋，当前步骤高亮，其余变淡。试管是自己画的。页面不写原品牌名，不用对方标志和文案。

键盘可以用方向键、Home、End 切换步骤，焦点环看得见。系统开启减少动态效果时，取消待执行的帧，直接停在这一步的螺旋上并同步画完。关掉减少动态后也按当前选中形态同步再画一帧，这次切换不申请动画帧。窄到 320 宽时不横向溢出。
