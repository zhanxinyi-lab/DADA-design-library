## 复刻说明

自包含单文件，无外链。原帖正文是 “make it pop: 002”，没有代码、字体或许可证。这里不嵌入原视频，也不使用原站素材。

对照的是本地预览片：720×720、30fps、约 8 秒。片头是浏览器窗口，效果本身是黑底上的两行字。

“make”和“it”是实心白字。“pop”三个字母内部是一层流动的彩虹镭射，有亮纹，也有接近黑的色谷，不是整屏背景。指针靠近“pop”时，颜色绕着指针搅动，并在最近的笔画上亮一块。指针离开后搅动退去，字母里的流动还在。

字用系统字体（Arial Black 及其回退），不引外链字体。窄屏把整组字缩进视口，仍然是两行。系统开启减少动态效果时，停在一帧静态镭射，指针不再搅动。

画布上下文丢失时改用同一套二维绘制；恢复后回到着色器。减少动态时丢失或恢复都只补那一帧，不另开循环。
