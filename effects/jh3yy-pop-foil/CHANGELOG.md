# 更新记录

## 1.0.3 — 2026-11-28

- 减少动态时，回车或空格的结束位置、方向键累加后的位置，都把白色圆标收进画面内，连描边离边缘约 5px。窗口改变大小后再收一次。
- 正常动态的指针路径和沿字母搅动的那一段没有改。

## 1.0.2 — 2026-11-28

- 整组字可以 Tab 聚焦，焦点有白环。聚焦后用和指针相同的距离搅动；方向键移动搅动中心；回车或空格沿字母搅动一次再退去。
- 减少动态时仍停在一帧。键盘操作改白色圆标和底部文字，不另开流动。
- 来自目录接线复审：键盘原先无法触发箔面变化。

## 1.0.1 — 2026-11-24

- 指针距离衰减改成从 0 到 0.58 的 smoothstep 再取补。远处仍是 0、近处仍是 1，不再依赖边界写反时的未定义结果。

## 1.0.0 — 2026-11-24

- 首次收录。黑底两行字：make 和 it 为白色，pop 内部是流动的彩虹镭射。指针靠近时颜色在字母里搅动，离开后搅动退去、流动还在。
- 减少动态时停在一帧静态渐变。窄屏缩小字号，不溢出。上下文丢失时改画二维，恢复后重接。
