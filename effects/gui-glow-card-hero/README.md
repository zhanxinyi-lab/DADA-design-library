## 复刻说明

自包含 Canvas 单文件，无外链。保留暖色玻璃主体、指针光效、W. 字标、地面反射和碎片式卡片转场。改脚本顶部 `const BRAND` 可换品牌名、字标和卡片文案；点击画面或按 Enter/空格可切换，读屏器会播报当前卡片内容。系统运行中开启减少动态效果时立即停用自动转场并静态呈现；关闭后恢复动画。减少动态效果时仅在交互或尺寸变化时重绘。
