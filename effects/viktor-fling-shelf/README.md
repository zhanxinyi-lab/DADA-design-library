## 复刻说明

自包含单文件，无外链。原帖没有代码、仓库或许可证。这里不声称已获许可，也不复制页面、照片或品牌字。

对照的是本地预览 `preview.mp4`，用 ffprobe 量过，不是照抄登记里的「约 8 秒」：

- 720×406，30 fps，240 帧，时长正好 8.000 秒
- 底色接近 `rgb(249, 240, 232)`

只做两下：

- 约 2.40 秒到 3.50 秒：货架被向左甩动。按住时画面大约每帧左移 11 像素；大约 3.00 秒后开始减速，到 3.50 秒停住。
- 约 4.60 秒到 4.83 秒：点开当前这件，旁边的衣服让开。
- 约 5.53 秒到 5.90 秒：衣服从粉色连续变成暖黄，大约 0.37 秒，中间色都在，不是硬切。

页面里的衣服是自绘色块。没有做整站导航、大字标题、品牌名、产品名、服装照片，也没有做 6.5 秒之后那件小衣服飞进角落的加购。

拖动跟手。松手后按松手速度继续走一小段，再弹回最近的一件，中间会略微冲过再回来。点一件就打开，选颜色时用大约 0.38 秒把当前颜色过渡到下一色。左右方向键翻一件；打开之后，方向键改颜色。焦点用键盘时可以看见。

系统开启减少动态效果时，翻页、回弹和换色都直接停在终态，不再排后续动画帧。指针移动和窗口尺寸变化合并到同一帧里处理；动作停稳后不再申请动画帧。
