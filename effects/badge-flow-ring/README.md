## 复刻说明

自包含单文件，无外链。浅灰底上三枚徽章：锯齿圆章加对勾、圆角六边形加闪电、八瓣星章加星。图形是自己画的 SVG 路径，没有搬原片、截图或品牌素材。

静止时三枚都是灰的，图标是白色。指针靠近时该枚亮起：边缘一圈彩色渐变沿轮廓流动，内部是同色系柔光，外面有一圈发光，徽章轻微上浮放大。颜色相位各不相同。旁边的徽章只在靠近指针的一侧渗出颜色，离开后平滑回到灰色。

窄屏和触摸没有悬停，点按一枚会点亮，再点一次或点另一枚会切换。键盘 Tab 到徽章上，效果与悬停一致。系统开启减少动态效果时，渐变停在各自的相位上，不再流动，出现和消失改为瞬时切换。
