## 复刻说明

自包含单文件，无外链。clean-room：只对照约 8 秒预览（720×474）和随包静帧里看得到的画面自己写。没有使用原站脚本、着色器、字体或图片。

浅灰白的作品格子铺满圆角画面。指针划过时，格子像软布一样被揽弯，松手后弹回去。格子会在较密的分格、不规则作品墙和更大的区块之间重新划分；导航和底部搜索留在作品墙上。左下角 Debug 会把格子收进中间的线框里，变成缓慢翻动的卡片，再回到作品墙。

画面上的名字、Index / Writing / About、Designer / Developer、Search、Debug 是预览里看得到的界面。搜索用的是演示作品名，不是原站项目。Index 在三种分格之间自己换；Writing 收成横向区块，About 收成四块大面，不是原站的文章页。

系统开启减少动态效果时，不再自动换分格，也不再翻动卡片；指针只轻轻带动格子。
