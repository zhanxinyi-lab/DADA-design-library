## 复刻说明

原帖只有两张静图，站点没有 preview 或视频。一张是浅色界面，一张是深色界面，提示区都套着一圈偏紫的软环。浅色环大约是 `#E5E5FB` / `#D9D8F7`，深色环大约是 `#23253F` / `#2A2C4F`。提示文字旁边有一枚可去掉的指标芯片。

这一页只保留这个交互：聚焦时出现软环，选中的指标以芯片留在提示里。原图里的整页报表、导航、图表和英文原句都没有照搬。芯片用的是自拟字段名，不是原图里的那个字段。

点页面空白处，软环消失。右上角可切换浅色和深色。系统开启减少动态效果时，软环直接切换，没有过渡。
