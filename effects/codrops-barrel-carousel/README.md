## 复刻说明

单文件、自包含。画面对应 Codrops 对 Mathias Adolfsson 作品集的公开案例，以及原帖 12.6 秒视频里能看到的运动：一排项目卡弯成前半段椭圆，拖拽或滚轮旋转并带速度形变和轻微色差；桌面端光标会让所在卡片鼓起、机位轻轻跟随，高光往反方向走。点开一张卡，它从所在位置展平并铺满画面，其余卡片退去，随后竖向图片以桶状弯曲进入。滚动越快，桶壁越弯；停下后回到接近平面。左右切换时画廊横滑换组，背后的主图立刻换掉。

案例正文没有放出可复用的完整工程，也没有单独的代码许可。这里不引用 Nuxt、Three.js、GSAP、Codrops 源码或原站图片，姓名、项目名和封面都是原创占位。几何关系按公开说明用自己的着色器重写：卡片沿水平方向随弧度弯曲，画廊沿垂直方向随滚动弯曲。

改脚本顶部的 `BRAND` 可换名称、年份和项目。拖拽旋转，点击卡片打开；打开后可纵向拖拽或滚轮滚动，用两侧按钮、方向键或横向拖拽切换项目，Esc 或「关闭」返回。触控不跟手鼓起，高光留在卡片中央。系统开启「减少动态效果」时，弧形直接到位，打开和关闭不播放过渡，画廊也不再弯曲。
