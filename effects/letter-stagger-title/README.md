## 复刻说明

只抽了超宽标题逐字出现、再落到一行这个动作。没有做废土场景，也没有做品牌站的导航、页脚和后面的转场。

自包含单文件，无外链。对照仓库里的原帖 `preview.mp4`：OpenCV 实测 720×540、30fps、240 帧、8.000 秒。字母不是整段一起切进来：先是中间一个字母落定，左右两端再进来，中间的字母随后滑进空位。约 2 秒后整行才齐。后面的沙漠和人物不在这次范围内。

页面用中性词 VECTOR，不写原标题，不搬原片画面、字体或站点标识。字用系统黑体（Arial Black、Impact 及回退）。

滚动、点击横向位置、拖动，以及方向键、PageUp / PageDown、Home、End，改的是同一段 0 到 1 的进度。进度增加，字母按既定顺序逐个出现并落到自己的位置；进度减小，后到的字母先沿原路收回。停下就停在当前这一帧，没有另外的时间轴。

系统开启减少动态效果时，直接给出完整标题，不排动画帧。这时滚动、点击和键盘不再改进度。这个偏好打开或关掉时都只重画一次；关掉后按关掉前的进度画，不另开动画。

窄到 320 和 390 宽时标题缩进视口，页面没有横向滚动。

原来的 `preview.webm` 是原帖压缩版（480×360、30fps、180 帧、6.000 秒）。现已换成打开 `code/index.html` 后自己录的屏：1280×720、25fps、207 帧、实测 8.28 秒。画面从空行开始，字母逐个落到 VECTOR，短暂停住，再按同一进度收回。不是把原帖 mp4 重编码。`preview.mp4` 仍是原帖参考。`duration_s` 按这条自录的整秒时长记为 8。
