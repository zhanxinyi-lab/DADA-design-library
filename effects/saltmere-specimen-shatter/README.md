## 复刻说明

自包含单文件，无外链。标本、粒子和背景都是 Canvas 自绘，不使用原片截图、原站照片或品牌名。

站点预览 `preview.mp4` 用 OpenCV 实测为 720×406、30fps、240 帧、8.0 秒。清单里写的约 59 秒和文件不符。画面是一整页海岸产品站：中间一件标本被拖着转动，随后碎成亮粒子，再聚成下一件。导航、文案、数据卡、底栏和背景照片都不在这次范围内。

这里只留这一下：

- 打开先看到一颗粒子球体，可以按住拖着转，松开后还带一点惯性。
- 松手，或按下一件 / 右方向键、下方向键，球体会连续碎开再聚成下一件。不是两帧硬切。
- 下一件在球体、圆盖、螺壳、水母之间循环。造型是自编的点云。
- 系统开启减少动态效果时，直接换成下一件，不排粒子动画，松手也不再滑行。
- 动画停稳后不再申请动画帧。指针移动和窗口缩放都合并到下一帧再处理。
