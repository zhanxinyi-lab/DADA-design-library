## 复刻说明

对照 `site-data/x-material-library/assets/2119797138276471067/preview.mp4` 看过。文件是 720×540、30fps、实际 8.00 秒；目录里的 `duration_s` 写成 16。

画面是深色折面上的三枚玻璃胶囊，字是 Payment、Review、Confirm。品红液体不是整颗变色：

- 指针刚碰上第一步时，液体从左缘鼓起来，顶上有一条亮边。
- 往右走时，液体先从这一侧鼓出一段偏粗的颈，拉长以后变细，断点跟着指针走，宽度收到接近 0 后断开。断开的两边各自往回抽一点，不是整段色带突然消失。下一枚被灌满之后，中间留下一条细腰。
- 颈贴上下一枚之后才把它灌满。指针还停在哪一枚，哪一枚就留着文字；已经被液体盖住、指针已经离开的步骤收成白色对勾。
- 指针挪到第三枚左缘时，前两枚都是对勾，中间仍是细颈，第三枚还没灌满。
- 指针离开这排之后，多出来的液体缩回去，只留第一步点亮和对勾。缩回时有一次轻微回弹，不是匀速淡出。

折面和液体里都有细颗粒。背景折面是另画的，不使用原片截图，也不画假光标。整排放在画面中间，窄屏仍保持横排，字号和间距缩小，避免被裁掉。

鼠标滑过、触控按住，或 Tab 后用方向键，走的是同一团液体。鼠标离开这排后缩回第一步。触屏点在某一步上松手会停在那一步，不会被抬手当成离开；点到胶囊外面才缩回。键盘焦点还在某一步上时不缩。`prefers-reduced-motion` 时不再逐帧滑动：默认停在第一步灌满的静帧，点选或聚焦直接换成那一帧，并停在所点的步骤，直到再点别的或点到外面。无外链。
