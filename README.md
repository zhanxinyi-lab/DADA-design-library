# DADA Design Library

DADA 的设计素材与创意代码库。每条素材按效果独立收录，方便预览、复用和继续迭代。

站点：https://x-material-library.workers.xd-sites.com

## 目录

- effects/<素材 ID>/README.md：素材分类、状态和原文链接
- effects/<素材 ID>/code/index.html：可直接打开的自包含复刻代码

## 状态

- video_recreated：根据原视频复刻
- ai_recreated：AI 复刻
- needs_recreation：待复刻

源码目录会持续补充和更新。
