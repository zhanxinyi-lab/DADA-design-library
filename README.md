# DADA Design Library

DADA 的精选设计素材与创意代码库。按效果目录收录。

站点：https://x-material-library.workers.xd-sites.com

目录：

- 网页实验
- 3D 与空间
- 角色与插画
- AI 工具

每条素材使用 effects/<效果名>/ 独立目录，例如 sonia-aurora-loader。目录名只用小写字母、数字和横线；素材 ID 写在 README 里。已复刻效果放在 code/index.html。

可交互预览：

- tlg-fluted-glass：棱纹玻璃。MIT 源码在 effects/tlg-fluted-glass/code/，许可证见同目录 LICENSE。
