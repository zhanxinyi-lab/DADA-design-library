# 上游快照

这些项目原来会单独出现在 zhanxinyi-lab 的仓库列表里。现在收在这里，账号首页只保留设计库、skills 和自动化看板。

每份都是上游默认分支的一份快照，许可证文件原样保留。`effects/` 里的同名目录仍是库内预览，不是这里的全文。

GPL-3.0 的 `mascots` 和 `procedural-expression-library` 只放在本目录，不并进 `effects/`。
